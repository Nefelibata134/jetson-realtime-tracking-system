# Tiny 输入尺寸开发验证 v2 结果

## 数值实时门槛通过，但真实事件负载未通过

2026年9月5日，Tiny416/Tiny640 在同一 MAXN_SUPER + `jetson_clocks` 条件下完成了
CSI 1280×720 对照。两者未舍入有效 FPS 均≥30、E2E P95≤33.33ms，测量采集丢弃、
序列缺口和标注视频丢弃均为0；每段标注视频3600帧全部可解码。
但入口入侵、穿线、停留事件均为0，未生成截图或事件片段，故
[v2协议](tiny_resolution_development_v2.md)的**带事件完整链路门槛为 FAIL**。
它只能支持当前未触发事件负载下的数值实时性，不能证明活跃事件I/O、60分钟稳定性或
默认替换已通过。CAVIAR development、参数搜索和holdout均未执行。

同批MOT17 GT补充诊断显示：Tiny640扩大了小目标覆盖，但共同覆盖轨迹的绝对中断也有
增加，不能只归因于新增目标。[原25W同阈值结果](tiny_resolution_results.md)与旧门槛
FAIL原样保留。CSI与MOT不是同一输入、功率或计时方式，不能混合成一个质量/速度结论。

## 同批小目标覆盖增加，共同覆盖组仍有中断回退

只重算既有四段calibration预测，未重新推理或调参。有效GT共335条、85894观测，
其中136条轨迹至少有一个原图高度<100px观测。小目标观测分母固定15891；与检测召回
不同，下面的覆盖率使用TrackEval CLEAR IoU0.5匹配后的跟踪观测。
所有整体及逐序列精确值、删失漏配、连续区段分布见
[诊断CSV](tiny_resolution_continuity_v2.csv)；官方HOTA/DetA/AssA/IDF1/MOTA/Recall/
Precision/TP/FP/FN/IDSW及各阶段延迟仍以[原结果](tiny_resolution_results.md)为准。

按小目标观测是否至少匹配一次划分同一批GT，四组互斥且覆盖全部136条。覆盖率分母只含
该组<100px观测；中断沿用旧“匹配→漏配→重新匹配，按首次漏配帧高度分组”的绝对计数。

## 配方、证据与仍需验证的项目

使用IMX219 sensor0/mode4，1280×720/60采集经既有videorate交付30FPS，输入队列2、
视频队列4、warmup300、测量3600帧；阈值0.10/0.45/0.30/0.40/0.80，buffer30。
ROI、有限竖线、3秒停留及输出设置全部来自冻结[v2配方](../../configs/benchmarks/tiny_resolution_development_v2.json)。
不把60→30设计转换称为应用丢帧，也不把应用零缺口称为传感器曝光零丢帧。
E2E为appsink后应用采集时间戳到同步事件I/O及视频提交完成，不是曝光到落盘。
全部P95分别计算，不相加、不平均。

软件是L4T36.4.3、`nvidia-jetpack 6.2.1+b38`、TensorRT10.3.0.30、nvcc12.6.68，
SoM P3767-0003；源码基于`3b48161e50b43831b1577764a02869de62b22420`的137文件候选快照，
不是仅凭该commit即可复现的干净构建。实际二进制、源码清单、配方、engine及原始结果SHA-256，
完整命令行（仅仓库根目录脱敏）和每模型精确指标见
[机器可读证据](tiny_resolution_development_v2_evidence.json)。模型、人物图像/视频、GT、运行目录
和逐GT原始诊断不随仓库分发；原始证据不覆盖。61份稳定文件回传校验与两视频完整解码通过。

主机Release/GStreamer构建、16项CTest、x264专项、83项Linux Python测试、6项临时执行器
保护测试、Shell语法、发布和diff检查通过。Windows仍有1项WinError1314符号链接权限失败，
8项POSIX测试跳过；不能表述为跨平台全部测试通过。连续性Notebook重新执行并核对
源哈希、分母、时长及官方计数通过。

后续先确认全身和地面可见、底边中心可进入既定ROI并越过有限竖线，用新目录重复CSI对照。
未完成真实事件与截图/片段复核前不进入CAVIAR、调参或60分钟验证。若需改变几何配方或
统计范围，应另行冻结版本。即使短测通过，也仍缺CAVIAR逐类事件质量、最终配置60分钟
稳定性及新的独立外部验证；720p/30不自动授权默认替换，1080p不是本轮阻塞项。

后续独立轮次见[带事件CSI复测](tiny_resolution_csi_event_retest.md)。本页零事件轮次的全部
数字与FAIL保持原样；后续4/5条事件的观测不回填到本轮，也不替代本页同GT连续性诊断。
功率口径补充：原始VDD_IN表示模组输入功率；本页“整机”只用于区分非模型独占遥测，
不构成整块载板或插座输入功率测量。
